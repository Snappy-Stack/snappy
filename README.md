## ⚡ Welcome to the SNAPPY Stack

SNAPPY is an ecosystem engineered for speed, stability, and stunning design. This repository hosts the official template branches for the SNAPPY stack.

It fuses **Next.js 16 (App Router)** with **Payload CMS 3.0** running natively in the same instance, all deployed on the edge.

### 🌿 Repository Structure

This repository uses branches to distribute different SNAPPY templates.

- **`portofolio`** : The official public starter template.

_Note: Premium, proprietary templates are hosted securely and are only available to authorized developers via the CLI._

---

## 🚀 Getting Started

**Do not clone this repository manually.**

The SNAPPY stack is designed to be installed via its interactive core CLI, which handles automatic environment variable injection, structure setup, and template downloading.

To create a new project, simply run:

```bash
npx create-snappy
```

_The CLI will guide you through selecting a template and setting up your Supabase and S3 credentials._

## 🔐 Licensing Requirements

This repository contains the template shells which depend on the secured `@snappy-stack/core` package.

> [!CAUTION]
> Running the `@snappy-stack/core` engine requires an active **SNAPPY Development License**.  
> Your `SNAPPY_LICENSE_TOKEN` must be present in your `.env` file. Without a valid license, the core engine's integrity locks will structurally degrade the UI and disable CMS initialization.
